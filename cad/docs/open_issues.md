# Open issues — what the CAD knows is not settled

**Purpose:** the ONE list of unsettled things a session should know before trusting a number or a fit: fit problems
the model carries knowingly, `[ESTIMATE]` values waiting for a measurement, hardware not modelled yet, mappings
not confirmed, parts not converted yet, known-broken / pending items. **Rule:** when you flag something in a commit,
add a row to its section (the issue and where it lives, and what closes it and the commit that raised it where its
table has those columns); when you close it, delete the row and say so in the commit message. A number here is
a fit value or an estimate, quoted beside the constant or test that holds it — the code wins if they drift; counts
and totals are never quoted (`cad/AGENTS.md` Docs).
